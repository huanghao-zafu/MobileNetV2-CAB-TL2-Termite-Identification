# 08 — Data and Release Changelog

## V1.1.0 — 2026-09-24 / 2026-09-25 (this release)

**Scope: make the manuscript Data Availability Statement fully true.**

### Added
- Architecture package `models/` (CAB, ECA control, backbones, MobileNetV1 / DenseNet builders, model registry, TL2 strategy), extracted verbatim from `train_termite_cls.py` so training and evaluation share one definition
- `mobilenet_v1.py` and `models_builder.py` — imported by the training script but never committed before
- `docs/` documentation set: `data_description.md`, `01_REPRODUCIBILITY_GUIDE.md`, `02_DATASET_CATALOG.md`, `03_FIGURE_TABLE_MAP.md`, `04_DATA_AVAILABILITY_STATEMENT.md`, `05_CODE_MANIFEST.md`, `06_RELEASE_MANIFEST.md`, `07_LICENSE_AND_CITATION.md`, `08_DATA_CHANGELOG.md`
- `LICENSE` (MIT, code) and `LICENSE-DATA` (CC BY 4.0) — both were referenced but missing in V1.0.0
- `CITATION.cff`, `.zenodo.json` — referenced but missing in V1.0.0; Zenodo creator metadata corrected to the real authors
- `scripts/verify_release.py` release self-verification
- `sample_data_1024/` preview subset (5 images × 8 categories, 1024 px, ≈2.4 MB)
- Release assets: `TermiteData-256px-V1.1.0.zip` (reproduction-resolution dataset, SHA-256 manifest), `weights_cab_tl2_5seeds.zip`, optional `weights_baselines.zip`
- `requirements.txt` pinned to the manuscript Table 2 environment; `requirements-modern.txt` as tested alternative

### Changed
- README rewritten: no `[ TO FILL ]` placeholders; terminology aligned with the manuscript (CAB = Color Attention Block; TL2/DLR = differential learning-rate fine-tuning, described as such)
- Dataset distribution moved from an in-repo 18.9 MB RAR to a three-tier scheme (git preview / 256 px Release asset / full-resolution Zenodo master)
- `data_availability/` package folded into `docs/` as files `04`–`08`
- `docs/data_description.md` corrected: the study uses **8** species–caste categories (the previous text said five) and the counts now match [`02_DATASET_CATALOG.md`](02_DATASET_CATALOG.md)

### Removed
- `Huang_JAE_TitlePage_v1.docx` (manuscript material, out of scope for a code repository)
- `TermiteData.rar` (superseded; remains in V1.0.0 history)
- `models/modules/01.py` (1-byte placeholder with a non-descriptive name)
- `samples_data/images/` (40 full-resolution images, ~90 MB) — replaced by `sample_data_1024/`

### Dataset count reconciliation (closed 2026-09-25)
- Manuscript §2.1 states a curated pool of 4,000 images (8 × 500) — confirmed against `TermiteData/raw/`.
- The directory actually consumed by training and evaluation is the as-built working set: **4,416** images (train 3,220 / val 796 / test 400). The two numbers describe different stages of the provenance chain in [`02_DATASET_CATALOG.md`](02_DATASET_CATALOG.md) §2a and are **not** in conflict; no manuscript number needs changing.
